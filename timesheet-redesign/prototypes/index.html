v2 可交互：选择活动、提交确认 → 查看提交成功页 → 个人记录 / PM 待接收队列。
示例数据为虚构，规则标签对齐现有 PRD（Booking / 代发 / 日历）。

整合页 · 目标方案

工时 + 周报 + 价值观 · 一键提交

草稿确认工时、RIGOL 周报（带出上周 / AI 生成进展）、价值观周期与年度达标展示，同页一次提交。

🖱️ 点「AI 生成进展」→ 一键提交 → 流转页
 范式 A · 主推荐

草稿确认页

系统预填本周工时 → 勾选确认 → 一键提交。Timely AutoSheet / D365 Agent 风格。

🖱️ 点黄色行「选择活动」→ 提交 → 流转页
 范式 B

Assist 弹窗 + 简化 Grid

进页先弹推荐项目 → 一键加入 → 再在简化表格里微调。Deltek 风格。

代表：Deltek Vantagepoint
 范式 C

日历时间轴

按时间顺序展示会议/工作块，拖到项目活动上归类。移动 & 会议场景。

代表：Timewatch、Timely Timeline
 范式 D

卡片 My Work

每条活动一张卡片，AI 建议 ⚡ 一键记工。Jira/Tempo 风格。

代表：Tempo Timesheets
 范式 E · 补充入口

Bot 对话记工

飞书 Bot / Teams 中用自然语言补记、改记工时。辅助而非主界面。

代表：SAP Joule、Deltek Teams
