# 目标架构与飞书集成

**状态：** 草案

---

## 1. 目标架构

```
体验层：PC Web │ 飞书 H5/小程序 │ 飞书 Bot/待办
    ↓
领域服务：Draft │ Submit │ Delegate │ Accept │ Query │ Notify
    ↓
规则引擎：Booking │ Budget │ Validation
    ↓
AI 层：CalendarClassifier │ ApprovalRisk（Phase 3）
    ↓
集成层：飞书项目 MCP/API │ 日历 │ 通讯录 │ RCMS
    ↓
数据层：PostgreSQL/MySQL │ Redis │ 消息队列 │ OLAP 副本
```

---

## 2. Master Data 归属

| 数据 | 主系统 | 工时系统角色 |
|------|--------|--------------|
| 项目/WBS/Booking | 飞书项目 | 只读消费 + 缓存 |
| 人员/部门 | 飞书通讯录 | 只读 |
| 日历/会议 | 飞书日历 | 事件消费 |
| 工时事实 | 自研工时服务 | 写入主库 |
| 预算 | RCMS | 接收前校验 |

---

## 3. 集成依赖

- 飞书项目 OpenAPI / MCP（Booking、WBS、项目状态）
- 飞书日历（会议、参与人、时长）
- 飞书待办 / IM（提醒、驳回通知）
- RCMS 预算接口（待梳理契约）
