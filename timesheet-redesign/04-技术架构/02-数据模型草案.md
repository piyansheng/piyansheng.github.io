# 数据模型草案

**状态：** 草案，待架构评审

---

## 1. 核心实体

| 实体 | 说明 | 关键字段 |
|------|------|----------|
| `weekly_timesheet` | 员工周工时单 | user_id, week_start, status |
| `timesheet_line` | 工时行 | project_id, activity_id, source_type |
| `timesheet_cell` | 日粒度小时 | line_id, work_date, hours |
| `draft_line` | 草稿行（未提交） | source: booking/delegate/calendar/manual |
| `delegate_record` | 代发记录 | sender, receivers[], event_id |
| `acceptance_queue` | 待接收队列 | pm_id, overflow_hours |
| `booking_snapshot` | Booking 快照 | 填报时点的 booking 状态 |

---

## 2. 三态分离

```
planned_booking  →  计划（飞书项目）
submitted_time   →  员工提交
accepted_time    →  PM 接收 / 自动接收
```

**禁止：** 三态混在同一字段覆盖写

---

## 3. 来源枚举 `source_type`

| 值 | 含义 |
|----|------|
| `booking` | Booking 自动带入 |
| `delegate` | 他人代发 |
| `calendar` | 日历 AI/确认 |
| `history` | 历史推荐 |
| `manual` | 手动添加 |

---

## 4. 状态机 `weekly_timesheet.status`

```
draft → submitted → (partial_)accepted → locked
         ↓
      rejected → draft
```
