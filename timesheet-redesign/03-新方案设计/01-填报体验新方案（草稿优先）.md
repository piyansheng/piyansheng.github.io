# 填报体验新方案（草稿优先）

**状态：** 核心讨论文档  
**关联：** 用户反馈最痛模块

---

## 1. 问题陈述

现有 **项目 × WBS × 7 天 grid** 让用户从空白开始填表 → 繁琐、不友好。

---

## 2. 目标体验

| 步骤 | 用户动作 | 系统行为 |
|------|----------|----------|
| 1 | 打开「我的本周」 | 展示 **Draft Engine** 生成的草稿 |
| 2 | 浏览列表 | 每行显示：项目、活动、每日分布、合计、**来源标签** |
| 3 | 微调 | 改小时 / 改备注 / 删行 / 加行 |
| 4 | 提交 | 工时规则校验 + 周报条数/必填校验 → **工时与周报一并提交** |

**理想耗时：** 5–10 分钟 review + 5 分钟写周报，而非 20–30 分钟从零填表。

---

## 2.1 RIGOL 周报联动（与工时同次提交）

工时并非单独提交，而是与 **RIGOL 周报** 在同一流程中完成。周报格式如下：

| 章节 | 标题 | 规则 |
|------|------|------|
| 一 | 上周重要工作进展回顾 | **限 3 项**，每项含工作描述 + 进展说明 |
| 二 | 本周工作计划 | **限 3 项**，每项含计划工作描述 |
| 三 | 需要的支持/帮助/资源 | 选填 |
| 四 | 工作建议及其他说明 | 选填 |
| 五 | 周报附件 | 选填 |

**产品含义：**
- 新系统 UI 应 **同页或同向导** 呈现「工时草稿 + 周报编辑」，一次提交
- Draft Engine 可 **辅助预填周报**：从本周工时行、Booking、飞书项目进展聚合建议条目（员工确认后写入）
- 一/二章节 **≤3 条** 需在提交前硬校验

## 3. Draft Engine 三源合并

```
┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│  Booking    │  │  代发/会议   │  │  日历 AI    │
│  自动成行    │  │  累计成行    │  │  未分配块    │
└──────┬──────┘  └──────┬──────┘  └──────┬──────┘
       └────────────────┼────────────────┘
                        ▼
                 Weekly Draft Lines
                        ▼
              ┌───────────────────┐
              │  草稿首屏（列表）   │
              │  [可选：表格视图]   │
              └───────────────────┘
```

| 来源 | 规则 | UI 标签 |
|------|------|---------|
| Booking | 项目/活动锁定；Booking 删除后可改 | `Booking` |
| 代发 | 项目/活动锁定；累计下限 | `代发·张三` |
| 日历 | AI 推荐项目活动；可 drag 调整 | `日历·会议名` |
| 历史 | 近 30 天常用项目推荐新增 | `推荐` |
| 手动 | 完全自选 | `手动` |

## 4. PC 页面线框（草案）

```
┌────────────────────────────────────────────────────────────┐
│  W21 · 2026/05/17–05/23          本周 44.5h  待确认 2h    │
│  [确认并提交]  [保存草稿]  [切换表格视图]  [+ 手动添加]      │
├──────────────┬─────────────────────────────────────────────┤
│ 周汇总        │  草稿列表                                    │
│ · 模板类 85%  │  ☑ 战略运营 › 项目实施    16h  Booking       │
│ · 饱和度条    │  ☑ 业务方案 › 后台系统     8h  代发·李四      │
│ · 色块图例    │  ☐ 未分配：技术讨论 2h     2h  日历 [选活动▼] │
└──────────────┴─────────────────────────────────────────────┘
```

### 4.1 列表行展开

- 每日小时可 inline 编辑（或展开子 grid）
- 备注默认自动填充，可改
- 代发行显示发送明细弹窗

### 4.2 表格视图（兼容模式）

- 保留现有 grid 交互，供习惯 Excel 的用户
- 数据与草稿列表 **同一数据源**

---

## 5. Assist 进页弹窗（可选）

参考 Deltek：首次进入本周时弹窗

- 本周假期/非工作日提示
- 「推荐添加的项目行」一键加入
- 可 Snooze / 不再提示

---

## 6. 校验规则（继承 PRD）

- 0.5h 步进、一位小数
- 单日 ≤ 24h
- 重复「项目+活动」不可提交
- 非工作日可填但置灰
