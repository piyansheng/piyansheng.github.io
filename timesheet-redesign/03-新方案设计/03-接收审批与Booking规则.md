# 接收审批与 Booking 规则

**状态：** 规则已定，UI/AI 待讨论

---

## 1. 业务规则（继承 PRD，不改）

| 规则 | 说明 |
|------|------|
| Booking 内 | 自动接收 |
| 超 Booking | PM 审批 |
| 超预算 | 不可接收，提示变更预算 |
| 累计超排期 | drill-down 明细 |
| 日常项目 | 整合单表 + 其他部门标签 |
| 驳回 | 修改重提 / 一键转日常 |
| 超时 | 自动接收 → 通知 PQA |
| 预算不足 | 升级 PFC |

---

## 2. UI 改造方向（非规则改造）

| 方向 | 说明 |
|------|------|
| 例外优先 | 默认只展示「待接收」，「全部」可切换 |
| 批量操作 | 按项目/按周批量接收（已有，优化交互） |
| 移动 PM | 仅 **提醒 + 快捷批核**，完整审批仍以 PC 为主 |

---

## 3. AI 审批建议（Phase 3）

| 能力 | 说明 |
|------|------|
| Risk Score | 超 Booking 比例、突增、非团队成员等 |
| 建议操作 | 建议通过 / 建议驳回 / 需关注 |
| 硬规则优先 | 超预算 AI 不可 override |
