# 分阶段里程碑

**状态：** 草案

---

## Phase 1 — MVP 基座（0–3 月）

**目标：** 低代码迁出 + 能力 parity，不改用户主路径也可上线

| 交付项 | 说明 |
|--------|------|
| API-first 工时服务 | 替代低代码核心链路 |
| 填报/代发/接收 parity | 保留全部 KEEP 规则 |
| Actuals 三态模型 | planned / submitted / accepted |
| 飞书项目 + 日历集成 | Booking、会议事件 |
| 移动 Phase 1 | 日程确认 + 代发 |
| 待办提醒 | 填报/接收/驳回 |

**不包含：** Draft 首屏、AI 分类扩展、分析看板

---

## Phase 2 — 体验升级（3–9 月）

**目标：** 解决「填表繁琐」核心痛点

| 交付项 | 说明 |
|--------|------|
| Draft Engine | Booking + 代发 + 日历三源 |
| PC 草稿首屏 | 列表默认 + 表格切换 |
| 日历 AI 扩展至 PC | 统一日程与周填报 |
| 移动完整 review | 时间轴确认草稿 |
| 个人周分布图 | 基础报表 |

---
